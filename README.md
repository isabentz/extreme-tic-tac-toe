# extreme-tic-tac-toe

Hi! Extreme tic tac toe has been one of my favorite games to play in dull moments since I was a kid, so I decided to try giving it a go to code it with Claude. I started by creating some rough sketches in Illustrator of a big tic tac toe board with smaller tic tac toe boards in each of the spaces. Then, I went into Claude and got closer and closer to my dream online tic tac toe.

The rules are simple:
Win small boards to claim squares on the big board
You must play in the board corresponding to your opponent's last move
If that board is won or full, you can play in any available board
Win three small boards in a row to win the game

I wanted the UI aesthetics to resemble a retro arcade game so I asked Claude to make the colors black, neon green, and neon purple.
